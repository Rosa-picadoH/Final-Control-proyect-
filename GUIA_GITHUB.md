# Publicación en GitHub


1. Cree un repositorio en GitHub desde la carpeta raíz de este proyecto.
2. Revise con `git status` qué archivos se incluirán. No suba carpetas `bin`, `obj`, logs ni archivos con secretos.
3. Haga un commit que describa fielmente el estado actual, por ejemplo: `Preparación final: migraciones, UI y documentación`.
4. Publique el repositorio y confirme desde GitHub que se ven los archivos, el README

Antes de la entrega, verifique que el repositorio contiene `database/`, `FinalControl/Migrations/`, el manual técnico y el script de publicación.
